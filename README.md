# GuatequeRiders

Plataforma web para gestión de rutas, eventos, actividades de circuito, comunidad y merchandising de Guateque Riders.

## Desarrollo

- Frontend: React + TypeScript + Vite.
- Backend: Spring Boot + Java 17.
- Base de datos: PostgreSQL + Flyway.
- Pagos: Stripe Checkout.
- Email local: Mailpit.
